# Burgera — HTML & CSS Practice Project

🔗 **Live Demo:** [View Live Demo](https://olfateme.github.io/practice-2/)

A modern landing page built with **HTML5** and **CSS3** as my second practical project while learning Front-End Development.

## 📌 About The Project

This project was created as a hands-on exercise to strengthen my HTML and CSS skills by building a complete landing page from scratch.

The main focus was on creating a structured and visually engaging layout while practicing **Flexbox, CSS positioning, typography, backgrounds, spacing, hover effects, and reusable CSS classes**.

The project is based on a burger restaurant landing page design and was developed for learning and practice purposes.

## 🛠️ Technologies

* CSS3
* Flexbox
